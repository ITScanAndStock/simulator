# Simulator mockups

Copy of the Claude Design canvas "Maquettes simulateur CSP" as of 2026-10-08:
https://claude.ai/artifact/4kTM1r7k9J62MyXRzs4Amb (private, ask Robin for access).
The canvas is the reference; this copy is refreshed after each round of changes.

- `project/*.dc.html`: one file per screen, in the canvas format. They do not open standalone in a browser
  (they rely on the canvas runtime), but their markup and copy are readable.
- `project/canvas.json`: index of the canvas pages and screens.
- `M-*` = phone (390 px), `T-*` = tablet (834 px), `Etat-*` = state pages, `Toasts-*` = toasts per screen.
- `logo_csp.svg`: logo taken from clubsantepremium.com.

All figures shown are fictitious.
